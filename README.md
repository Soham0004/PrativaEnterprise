# Prativa Enterprise - Official Website

A modern, fully responsive business portfolio built for **Prativa Enterprise**, a leading construction firm in Kolkata with over two decades of foundational expertise. This front-end project serves as a digital storefront to showcase their legacy of quality construction, ranging from luxury riverside residences to large-scale urban infrastructure.

## 🌟 Project Overview
The goal of this project was to create a premium, trustworthy online presence that reflects the company's architectural expertise. The design utilizes a warm, professional color palette (incorporating deep oranges and soft blues) and modern UI patterns to guide users seamlessly through their services, history, and contact channels.

## ✨ Technical Features & UI Design
* **Advanced Layouts:** Built utilizing CSS Grid and Flexbox for a robust, fully responsive design that scales flawlessly from mobile devices to large desktop monitors.
* **Custom Architectural Accents:** Features bespoke CSS styling, including offset gradient frames and repeating linear-gradient textures to create a "construction-themed" aesthetic without relying on heavy image assets.
* **Interactive Elements:** Includes smooth, tactile CSS transitions and "lift" hover animations on form buttons to enhance user experience and interactivity.
* **Dynamic Portfolio Sections:** Cleanly structured content blocks highlighting diverse project categories (Residential, Commercial, and Infrastructure).
* **Optimized Contact Form:** A beautifully styled, two-column form section designed for high readability and user conversion.
